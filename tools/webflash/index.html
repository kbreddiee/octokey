espkvm web flasher

Plug the board in via USB, click the button, pick the serial port. Pick one hub image below — they're alternatives, not a set to install together.

Hub — ESP32-S3 DevKitC-1 (OLED + rotary encoder)

Use the port labelled UART on the DevKit. Includes the dongle-provisioning pack (flash dongles later from the hub's USB-A port — see PAIRING.md).

Hub — LILYGO T-Embed (built-in screen + knob)

Hub — custom PCB (button + 10 slot LEDs, no display)

See hardware/hub-refdesign/.

Hub — espkvm Air (Wi-Fi only, phone is the keyboard)

No USB host needed — any ESP32/S2/S3/C3 board with just power. After flashing, join the Wi-Fi network it broadcasts (default SSID espkvm) and open http://192.168.4.1/.

Dongle — ESP32-S2 Mini

Hold 0 (BOOT), tap RST, release 0 first — the S2 Mini needs to be in download mode.

Dongle — LILYGO T-Dongle-S3 / M5Stack AtomS3U (ESP32-S3)
