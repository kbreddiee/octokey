OctoKey

Flash your dongle from the browser

OctoKey turns a LILYGO T-Dongle-S3 into a wireless USB keyboard, mouse & macro runner — one phone drives up to ten machines, with no software to install on any of them.

Install OctoKey

Connect the dongle, then click below. Takes about 30 seconds.

⚠️ Your browser can’t flash over USB. Open this page in desktop Chrome, Edge or Opera (Web Serial isn’t available in Firefox, Safari, or on phones).

⚠️ This page must be served over https (or localhost) to access USB.

Before you start

  • A desktop computer running Chrome, Edge, or Opera. Flashing uses Web Serial, which phones and other browsers don’t support.
  • A LILYGO T-Dongle-S3 and a data USB-C cable (some charge-only cables won’t enumerate).
  • Two minutes. This erases the dongle and installs OctoKey fresh.

How to flash

  1. Put the dongle in download mode Unplug it. Press and hold the BOOT button, plug it into USB while still holding, then release after a second. (This is required — once OctoKey is running it becomes a keyboard and hides its serial port.)
  2. Click “Install OctoKey” Pick the new serial port in the browser dialog (usually labelled USB Serial or JTAG/serial), then confirm Install.
  3. Wait for “done”, then unplug & replug Plug it into the computer you want to control. Its little screen boots up showing the 0–9 slot bar.

Then, from your phone

  1. Join the Wi-Fi Network octokey, password octokey-air.
  2. Open the control panel Browse to http://192.168.4.1 — touchpad, keyboard, and saved macro scripts.
Heads up: OctoKey presents itself as a real USB keyboard and can type into whatever it’s plugged into. Only flash hardware you own, and change the default Wi-Fi password before using it anywhere shared.
